## Why

Activating Download CV currently navigates away from the portfolio. Opening the CV destination in a separate tab lets visitors access the document while keeping the portfolio available in its original tab.

## What Changes

- Open the configured Download CV destination in a new browser tab.
- Preserve the configured destination, button label, icon, and presentation.

### New Capabilities

### Modified Capabilities
- `portfolio-experience`: Specify that the Download CV call to action opens its configured destination in a new tab.

## Impact

- Updates the hero call-to-action link behavior in the client portfolio.
- Does not change the CV URL or the button's visual presentation.
