## ADDED Requirements

### Requirement: Microsoft .NET Framework 4 certifications are presented accurately
The portfolio MUST present the four supplied Microsoft .NET Framework 4 certifications with Microsoft as the issuer and 2013 as the year for every entry:
- WCF Development (70-513)
- Data Access (70-516)
- Web Application Development (70-515)
- Web Application Design & Development (70-519)

#### Scenario: Visitor views the certifications section
- **WHEN** a visitor views My Certifications
- **THEN** all four specified certifications are shown with their exact exam names and codes, Microsoft as issuer, and 2013 as the year

### Requirement: Certification imagery corresponds to each credential
Each certification entry MUST include an appropriate image corresponding to that credential and descriptive alternative text identifying the certification. An image MUST NOT be presented as an authentic official certificate or badge unless its authenticity is verified.

#### Scenario: Visitor views a certification image
- **WHEN** a visitor views a certification entry or uses assistive technology to interpret its image
- **THEN** the image visually relates to the corresponding certification and its alternative text identifies the credential
