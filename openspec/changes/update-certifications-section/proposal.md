## Why

The My Certifications section currently contains unrelated placeholder credentials. Replacing them with the supplied Microsoft .NET Framework 4 certifications and their correct year makes the portfolio's credential information accurate and useful to visitors.

## What Changes

- Replace the current certification entries with WCF Development (70-513), Data Access (70-516), Web Application Development (70-515), and Web Application Design & Development (70-519), all issued by Microsoft in 2013.
- Provide an appropriate image and descriptive alternative text for each certification while preserving the section's existing presentation pattern.

### Modified Capabilities

- Updates the certification content and image assets consumed by the client portfolio section.
- Does not change the section layout, navigation, or other portfolio content.
