## Purpose

Defines the header brand presentation so visitors see the configured logo image asset as the site mark with its accessible name preserved.

## ADDED Requirements

### Requirement: Header brand logo image
The portfolio SHALL render the header brand mark using the `em-logo-32.png` logo image asset instead of the "EM" text.

#### Scenario: Visitor loads the homepage
- **WHEN** a visitor loads the portfolio homepage
- **THEN** the header brand shows the `em-logo-32.png` image with the existing accessible brand name and home link behavior preserved
